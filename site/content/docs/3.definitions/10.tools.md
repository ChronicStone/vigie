---
title: Tools
description: defineTool adds an MCP tool of your own, with read or write scope.
---

```ts [definitions/tools/acme.ts]
import { defineTool } from '@vigiejs/sdk'

export const blockedShipments = defineTool({
  name: 'parcelo_blocked',
  description: 'Shipments to Parcelo that have not succeeded yet, with the reason.',
  scope: 'read',
  run: ({ sql }) =>
    sql(`SELECT LogAttributes['task.key'] AS subject, argMax(LogAttributes['taskOutcome.reason'], Timestamp) AS code, max(Timestamp) AS last, countIf(Outcome = 'succeeded') AS ok
         FROM logs WHERE $__timeFilter(Timestamp) AND Environment = $__env AND TaskKind = 'parcelo.ship'
         GROUP BY subject HAVING ok = 0 ORDER BY last DESC LIMIT 50`),
})
```

`run(ctx, input)` receives `ctx.sql`, which runs a read-only query with the same [macros as pages](/docs/definitions/pages#sql-macros), and `ctx.env`, the environment asked for. Whatever you return goes back to the agent as JSON. A caller can also pass `env` and `minutes` (the window, 60 by default), which set the macros.

Give the tool arguments with `input`, a JSON schema, and read them as the second parameter:

```ts
export const customerShipments = defineTool({
  name: 'parcelo_shipments_of',
  description: 'Every Parcelo shipment attempt for one order.',
  scope: 'read',
  input: { type: 'object', required: ['order'], properties: { order: { type: 'string' } } },
  run: ({ sql }, { order }) =>
    sql(`SELECT Timestamp, Outcome, LogAttributes['taskOutcome.reason'] AS code FROM logs
         WHERE $__timeFilter(Timestamp) AND Environment = $__env AND TaskKind = 'parcelo.ship'
           AND LogAttributes['task.key'] = 'order:${String(order).replace(/[^\w-]/g, '')}'
         ORDER BY Timestamp DESC LIMIT 50`),
})
```

Queries are built as text, so clean what the agent sends before it goes into one, as above. A `write` tool is only offered to tokens with write scope and to people who are not viewers.
