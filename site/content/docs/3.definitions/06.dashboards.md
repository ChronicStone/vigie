---
title: Dashboards
description: defineDashboard lays out widgets from SQL on a 12-column grid.
---

```ts [definitions/dashboards/acme.ts]
import { defineDashboard } from '@vigiejs/sdk'

export const shop = defineDashboard({
  id: 'shop',
  title: 'Shop overview',
  widgets: [
    { type: 'stat', title: 'Orders today', span: 3, sql: `SELECT count() AS v FROM logs WHERE $__timeFilter(Timestamp) AND Environment = $__env AND Route = '/orders/:id/checkout' AND Status < 400` },
    { type: 'lines', title: 'Checkout p95 (ms)', span: 9, sql: `SELECT $__bucket(Timestamp) AS t, quantile(0.95)(DurationMs) AS p95 FROM logs WHERE $__timeFilter(Timestamp) AND Environment = $__env AND Route = '/orders/:id/checkout' GROUP BY t ORDER BY t` },
  ],
})
```

Each widget takes a `title`, a `sql` query and optionally `span` (columns out of 12) and `height` in pixels. What the query must return depends on the type:

| `type` | The query returns |
|---|---|
| `stat` | One row: the first column is the number. Optional `unit` (written next to it), `format` (`number`, `ms` or `percent`; `ms` also formats the axis of `lines`) and `tone` (`error` or `warn` colours it when not zero). |
| `bars`, `lines` | A column `t` (`$__bucket(Timestamp) AS t`) and one column per series. `series` is another name for `bars`. |
| `table` | Any columns. |
| `list` | `label` and `value` columns, drawn as bars, in the order of your query. |
| `pie` | `label` and `value` columns. |
| `sparkline` | A column `t` and one value column: the last value is shown big, with its trend. |

The macros are the same as on [pages](/docs/definitions/pages#sql-macros).

Dashboards made in the app can be edited there, or by an agent over MCP (`create_dashboard`, `add_widget`). Dashboards in code are read-only in the app: change the file.
