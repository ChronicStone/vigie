---
title: Redactors
description: defineRedactor masks secrets in your paths and field names at ingest, before anything is stored.
---

Vigie already masks fields named like secrets (`password`, `token`, `authorization`, `cookie`, `secret`, `api_key`…), the segment after common secret paths such as `/reset-password/`, email addresses (`j***@acme.example`) and card numbers (`[CARD]`). Add your own:

```ts [definitions/redactors/acme.ts]
import { defineRedactor } from '@vigiejs/sdk'

/** Webhook and receipt links carry their secret in the path. */
export const acmePaths = defineRedactor({
  name: 'Acme secret links',
  paths: ['parcelo/webhooks', 'receipts'],
})

/** A field name of your own that holds a secret. */
export const acmeFields = defineRedactor({
  name: 'Acme field names',
  keys: /(^|\.)(iban|vatNumber)$/i,
  mask: '[HIDDEN]',
})
```

| Field | Masks |
|---|---|
| `paths` | The segment after each path: `/parcelo/webhooks/abc123` is stored as `/parcelo/webhooks/[REDACTED]`. |
| `keys` | Any field whose name matches the regular expression: its whole value is replaced. |
| `mask` | What replaces a field matched by `keys`. `[REDACTED]` by default. Paths always read `[REDACTED]`. |

Masking happens at ingest, on spans and logs: span names, attributes, log bodies and URLs. Metric attributes are stored as sent, so keep secrets out of them. **Settings, Redaction** shows what is active and what it caught.
