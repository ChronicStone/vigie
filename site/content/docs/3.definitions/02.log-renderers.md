---
title: Log renderers
description: defineLogRenderer turns a namespace of fields into a readable section, a phrase in log rows, and a sentence for agents.
---

A wide event can carry dozens of fields. A log renderer claims a namespace, such as `parcelo.*`, and says how to show it. Open an event on **Logs** and its fields appear as a titled section, drawn the way you wrote it, instead of a flat list.

```ts [definitions/renderers/parcelo.ts]
import { defineLogRenderer, ui } from '@vigiejs/sdk'

export const parcelo = defineLogRenderer({
  id: 'parcelo',
  match: 'parcelo.*',
  title: 'Parcelo',
  render: (e) => [
    ui.numbers({
      tracked: e.num('parcelo.parcelsTracked'),
      delivered: e.num('parcelo.parcelsDelivered'),
      unmatched: { value: e.num('parcelo.parcelsUnmatched'), tone: e.num('parcelo.parcelsUnmatched') ? 'warn' : 'neutral' },
    }),
    ui.fields(e, 'parcelo.', { hide: /parcels/, tones: { refused: 'error', rate_limited: 'warn' } }),
  ],
  row: (e) => (e.has('parcelo.parcelsTracked') ? `${e.num('parcelo.parcelsTracked')} parcels tracked` : null),
  text: (e) => `Parcelo ${e.str('parcelo.operation')}: ${e.str('parcelo.outcome')}`,
})
```

| Field | What it does |
|---|---|
| `id`, `title` | The id, and the title of the section. |
| `match` | A field namespace: `parcelo.*` claims every field that starts with `parcelo.`. Claimed fields leave the generic "other fields" list. Only one renderer can claim a namespace: the second file is reported as an error on **Settings, Extensions**, unless it has a `when`. |
| `when` | Optional. Render only when it returns true. |
| `render` | The section in the event panel, as a list of `ui` blocks. |
| `row` | A short phrase shown in log rows. Return `null` for none. |
| `text` | Plain text for MCP, Slack and AI prompts. |

A renderer runs only for events that have at least one field in its namespace. If `render` throws, the section shows the error and everything else on the event still shows.

## Reading the event

`e` reads flattened attributes: `e.str(key)`, `e.num(key)`, `e.bool(key)`, `e.has(key)`, `e.keys(prefix)`, and `e.attrs` for everything.

## Blocks

| Block | Shows |
|---|---|
| `ui.text(text, { tone?, mono? })` | A line of text. |
| `ui.numbers({ label: value })` | A row of labelled numbers. A value can be `{ value, tone }`. |
| `ui.kv({ label: value })` | Label and value rows. Empty values are dropped. |
| `ui.fields(e, prefix, { hide?, tones? })` | Every field under `prefix`, with `hide` (a regular expression on the field name) to leave some out and `tones` to colour values. |
| `ui.table(columns, rows)` | A small table. |
| `ui.badge(text, tone)` | A coloured tag. |
| `ui.callout(tone, text, title?)` | A boxed note. |
| `ui.meter(value, max, label?, tone?)` | A bar. |
| `ui.duration(ms)`, `ui.bytes(n)`, `ui.httpStatus(code)` | A number written the way people read it. |
| `ui.code(text)`, `ui.sql(text, note?)`, `ui.json(value)` | Code, a SQL statement, a JSON tree. |
| `ui.section(title, ...)`, `ui.stack(...)`, `ui.inline(...)` | Grouping. Empty children (`null`, `false`) are dropped. |

Links open the right screen: `link.task(id)`, `link.trace(id)`, `link.person(id)`, `link.account(id)`, `link.process(id)`, `link.route(id)`, `link.page(id)`, `link.url(href)`. Each takes an optional second argument for the text.

Tones are `neutral`, `ok`, `warn`, `error`, `brand` and `muted`.
