## Views

```ts
import { defineView } from '@vigiejs/sdk'

export const failedCheckouts = defineView({
  id: 'failed-checkouts',
  name: 'Failed checkouts',
  scope: 'logs',
  filter: JSON.stringify({ q: 'checkout', kind: 'request', level: 'error' }),
})
```

Shows up in the views list on **Logs**, beside the views people save in the app. `scope` is the screen (`logs`), and `filter` is the JSON that screen saves: `q` (the search text), `level`, `kind` (`request` or `task`) and `filters`. Save a view in the app once to see an exact example.

## Channels

```ts
import { defineChannel } from '@vigiejs/sdk'

export const pager = defineChannel({
  name: 'pager',
  send: async ({ title, text }) => {
    await fetch('https://pager.acme.example/hooks/vigie', { method: 'POST', body: JSON.stringify({ title, text }) })
  },
})
```

A notification channel of your own. It receives every alert message, firing and recovered, like Slack or email, as `title`, `text` and the full `notice`. `notify: 'pager'` on an [alert](/docs/definitions/alerts) targets it alone. If `send` throws, the error shows in the result of **Send a test** and other channels still get the message.

## Enrichers

```ts
import { defineEnricher } from '@vigiejs/sdk'

const plans = new Map([['acc_1', 'enterprise']])

export const plan = defineEnricher({
  name: 'Account plan',
  signal: 'logs',
  enrich: (attrs) => (attrs['account.id'] ? { 'account.plan': plans.get(attrs['account.id']) ?? 'free' } : undefined),
})
```

Adds fields at ingest, before storage. Keep it fast: it runs on every row.

## Health rules

```ts
import { defineHealthRule } from '@vigiejs/sdk'

export const backlog = defineHealthRule({
  name: 'Backlog over 500',
  card: 'flow',
  check: (facts) => (facts.due > 500 ? 'bad' : facts.due > 100 ? 'warn' : undefined),
})
```

Turns a card on **Tasks** red (`'bad'`) or amber (`'warn'`). `card` is `flow` (is work moving), `execution` (is it succeeding) or `liveness` (are workers alive). Return nothing to leave the card as it is: a rule can make a card worse, never hide a problem.

`facts` has `oldestDue` (seconds), `due`, `scheduled`, `failedShare` (in %), `attempts`, `workers` (the worker names seen in the last 5 minutes) and `lost` (attempts that lost their worker).

## People

```ts
import { defineIdentity } from '@vigiejs/sdk'

export const people = defineIdentity({
  name: 'Acme users',
  people: async () => (await fetch('https://api.acme.example/internal/users')).json(),
})
```

Turns `user.id` into names on every screen. Vigie reads the list at most once a minute, and uses only the first identity it finds.
