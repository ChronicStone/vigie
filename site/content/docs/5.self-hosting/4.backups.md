## Retention

| Data | Kept |
|---|---|
| Spans and metrics | 30 days |
| Wide events | 90 days |
| Per-minute rollups | 400 days |

ClickHouse drops whole days at once, so retention costs nothing and needs no job.

## Backups

Telemetry ages out on its own and is rarely worth backing up. The state is: people, alerts, issues, incidents, tokens, dashboards made in the app.

```bash
docker compose -f deploy/compose.yml exec vigie bun cli/vigie.ts backup
```

It copies the SQLite databases to a dated folder under `/data/backups`, while Vigie runs. Copy that folder off the server on a schedule.

Definitions are in your app's repository, so git already backs them up.
