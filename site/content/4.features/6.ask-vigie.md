---
title: Ask Vigie
description: Questions in plain words, answered from your telemetry with links to the evidence.
---

Set `VIGIE_AI_API_KEY` (and `VIGIE_AI_BASE_URL` for any OpenAI-compatible provider) to turn on:

- **Ask Vigie.** "Why did checkout slow down this morning?" It answers from the same tools agents use over MCP, cites trace ids, task ids and exact numbers, and links each one.
- **Explain.** On any event or issue, a short explanation of what happened, using your renderers and error renderers.
- **Search in words.** Type "failed emails to postwing yesterday" on **Logs**, and it becomes a filter you can see and edit.

The model is `gpt-4.1-mini` by default; set `VIGIE_AI_MODEL` to change it. Only what the tools return is sent to the model, after masking.
