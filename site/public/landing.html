  • ClickHouse has no published port. Vigie runs as a non-root user on a read-only filesystem.

Running before your coffee cools.

One command starts Vigie. ClickHouse comes from an installed binary, Docker, or a download, and ports that are taken move to the next free one.

  1. Run Vigie. On your machine with no sign-in, or on a server with HTTPS.
  2. Connect your app. The installer finds Vigie, writes the env, and links the app in the browser, so nobody copies a key.
  3. Open a request. Every request, error and job is one event, joined to its trace.
bunx @vigiejs/cli --seed

# the app on http://localhost:5310, ingest on :4318 # --seed sends a day of realistic telemetry # no sign-in, listens on this machine only

deploy/install.sh --domain vigie.example.com

# Docker, ClickHouse and HTTPS from Caddy # prints the owner's setup code and the first ingest key

node ace add @vigiejs/adonis

# traces from @adonisjs/otel, one wide event per request # background work through task()

npx @vigiejs/nestjs init

# adds VigieModule.forRoot() and the trace register # @VigieTask() on BullMQ processors and crons

OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318

# any OpenTelemetry SDK, any language # a log with method, status and durationMs is a request
